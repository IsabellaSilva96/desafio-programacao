## Resumo dos Conceitos Praticados

Durante as atividades propostas, foram desenvolvidas habilidades essenciais em HTML e CSS. Aprendi a criar a estrutura de páginas web utilizando diversas tags HTML e a aplicar estilos com CSS para personalizar a aparência, o alinhamento e a disposição dos elementos na página.

As maiores dificuldades estiveram relacionadas ao entendimento de algumas tags e propriedades do CSS, além da organização adequada dos componentes dentro da página. Também foram explorados conceitos importantes, como o uso de classes, seletores, atributos de estilo e a construção da estrutura de páginas web.
